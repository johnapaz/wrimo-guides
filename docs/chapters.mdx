Chapters live inside a project. The outline is built from headings in the chapter you're editing; it is not a separate document.

## Write a chapter

1. Open a project and choose **{ui.newChapter}** in the sidebar.
2. Replace the default chapter title in the title field above the editor.
3. Write in the main editing area. Use the toolbar to format text, make headings or bulleted lists, and undo or redo changes.
4. Select a chapter title in the sidebar to switch chapters. WriMo keeps your edits in the open project as you move between chapters.
5. Wait for **Saved locally** before closing the tab. Use **{ui.saveNow}** if you want to save immediately.

The word count at the bottom refers to the selected chapter, not the entire project.

## Navigate with headings

1. Select a line or place the cursor where you want a section heading.
2. Choose **Heading** in the toolbar.
3. The heading appears under **Outline** in the sidebar. Choose it to jump to that point in the same chapter.

Editing or removing a heading updates the outline. Switch chapters to see that chapter's headings. The current toolbar creates section headings; it does not offer a separate scene organizer.

There are no in-app controls yet for reordering, duplicating or deleting chapters. For protection against browser data loss, see [Saving and backup](./saving-and-backup.mdx).
