import {status} from '@site/src/facts';

| What you see | What it means |
| --- | --- |
| **{status.pending}** | You changed something that is not stored yet. WriMo saves it to this browser automatically within moments. |
| **{status.saved}** | Your latest writing is stored in this browser profile. It is not on GitHub yet unless the bottom bar also says it is backed up. |
| **{status.backedUp}** | The bottom bar shows this when your latest saved writing is also in a commit in your private GitHub writing repository. |
