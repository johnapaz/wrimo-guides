# What's new in WriMo 0.1.1

**Released November 14, 2026 (Eastern Time).** WriMo 0.1.1 makes it easier to find your drafts, manage Projects, and see what happened when GitHub sign-in was interrupted. The screenshots show a sample draft in the live app.

## Your Projects, where you expect them

When you open **Projects**, your drafts appear with the most recently edited first. Open a Project by selecting its title, or use **Rename** directly on its card. You can start a new Project without deciding on a name up front.

<img src={useBaseUrl('/images/0.1.1/projects-shelf.jpg')} alt="Your Projects shows the on-device shelf, a project with a Rename button, and the Restore a Project menu." width="1363" height="936" />

If you wrote something before signing in, it remains available on this device. **Copy and open** makes a separate copy in your signed-in space while keeping the original draft intact.

If you already have a backup, the recovery options now make the distinction between a **saved file** and **GitHub** easier to follow.

See [Projects and drafts](./projects) and [Recover your writing](./recovery).

## A clearer way back when GitHub sign-in doesn't finish

If you cancel GitHub sign-in, it expires, or it can't finish, WriMo brings you back to your writing and explains what happened. You can try connecting again or choose **Not now**.

**Important:** your writing remains saved on this device, but an unfinished sign-in **does not** mean it has been backed up to GitHub. WriMo says so explicitly.

<img src={useBaseUrl('/images/0.1.1/github-sign-in-return.jpg')} alt="A cancelled GitHub sign-in leaves the Projects shelf open and offers Try GitHub again or Not now." width="1363" height="936" />

See [Saving and backup](./saving-and-backup) and [Troubleshooting](./troubleshooting).

## More helpful WriMo screens

Invitation and GitHub-connection return screens now use WriMo's own presentation and clearer language. If you visit a page that doesn't exist, the page offers links back to the app and to its guides.

## Keep your writing safe

WriMo saves drafts locally. **Local saving and GitHub backup are different protections.** Before changing devices, removing browser storage, or resetting a test workspace, check that you have the backup or exported copy you need.

<img src={useBaseUrl('/images/0.1.1/writing-desk.jpg')} alt="The writing desk shows a chapter and a Saved locally status with no remote backup." width="1363" height="936" />

See [Saving and backup](./saving-and-backup), [Export](./export), and [Privacy and ownership](./privacy-and-ownership).
